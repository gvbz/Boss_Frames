# Changelog

## 1.2.0 (unreleased)

- **Show boss frames** toggle at the top of the window: turns the plates, minimap diamonds and alerts on or off.
- Optional chat alert when a boss comes into range, in the plate color. Once per boss; not again if it returns within 60 seconds; a respawned boss alerts again.
- Optional minimap diamonds for bosses in range, in the plate color.
- Removed the Nearby list; the plates show the bosses.
- The Add box shows "Monster name" inside it, so the Add buttons line up with it.
- Errors show in the status line in Manage Plugins.
- Requires client v146 or newer.
